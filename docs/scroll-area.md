# Scroll Area

A box that scrolls its content.

<Preview name="scroll-area-demo" />

## Usage

```go
ui.ScrollArea(twi.Class("h-10 w-30 rounded-md border"), rows...)
```

Give it a height. It is focusable, so the arrows, PageUp, PageDown, Home and End scroll it, as does the wheel over it. A focused element inside is scrolled into view.
